# Welcome to RustLRN - Learn Rust Interactively!

This tool will guide you through Rust concepts with interactive examples.

## What You'll Learn

- Rust syntax and semantics
- Memory management and ownership
- Error handling
- Concurrency
- Advanced patterns

## How It Works

1. Each lesson contains explanations and code examples.
2. Code blocks can be **edited** and **run** directly from this tool.
3. You can see compilation results in real time.
4. Learn at your own pace.

## Getting Started

### Navigation

- Press `n` to go to the next lesson.
- Press `p` to go to the previous lesson.
- Press `q` to quit.

### Working with Code

- Press `r1`, `r2`, etc. to run specific code blocks.
- Press `ed1`, `ed2`, etc. to edit code blocks.
- Press `z1`, `z2`, etc. to reset code blocks to their original state.
- Press `ed0` to write code from scratch.

### Setting Up Your Editor

To edit code, configure your preferred editor with the command:


`rustlrn editor <editor_command>`


## Your First Code Block

Try running this code:
